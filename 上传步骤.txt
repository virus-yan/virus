上传到 GitHub Pages 步骤
============================
1) 登录 github.com → 右上角 + → New repository
2) 仓库名填英文（例：brushquiz），可见性选 Public，勾选 Add a README file，点 Create repository
3) 进入仓库 → Add file → Upload files → 把本文件夹里的所有文件拖进去（保持文件名不变，不要多套一层文件夹）→ 点 Commit changes
4) 仓库 → Settings → 左侧 Pages → Source 选 Deploy from a branch
   → Branch 选 main，文件夹选 / (root) → 点 Save
5) 等 1~2 分钟，刷新 Pages 页面，会看到 Your site is live at https://你的用户名.github.io/brushquiz/
6) 手机浏览器打开这个网址 → 菜单里选“添加到主屏幕 / 安装应用”

常见问题
- 免费账号要选 Public 仓库，私有仓库不能开 Pages
- 仓库名用英文小写，别用中文或空格
- 打开后 404：确认 index.html 在仓库根目录，并再等 1~2 分钟
- 打开后是旧版本：浏览器缓存了 Service Worker，可在浏览器设置里清除该站点数据，或换个浏览器试
- 网址在国内偶尔打不开或很慢：可换 Cloudflare Pages，或继续用“局域网访问”的方式

注意
- 托管后所有知道网址的人都能打开这个软件（但里面不含你的题库，题库保存在各自设备的浏览器里）
- 不要把“预装题库”的版本上传到公开仓库，否则题目会被公开
